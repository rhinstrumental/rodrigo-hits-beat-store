# Rodrigo Hits Beat Store — V1

- Responsive dark Beat Store
- Search, genre/mood filters and BPM sorting
- Demo player
- Beat request form addressed to rhinstrumental@gmail.com
- No checkout, automatic payment or automatic download

## Demo audio
Put files in `audio/` named after the beat ID, e.g. `RH001.mp3`.

## Add beats
Edit `beats.js` and add objects using the same structure as the examples.

## Publish
Upload the contents of this folder to the GitHub repository, then connect that repository to Cloudflare Pages.
